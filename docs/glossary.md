# 用語

レポートに出てくる略語・名称です。

## ロボットとシミュレーション

| 用語 | 意味 |
|---|---|
| CRANE+ V2 | 4 自由度のアームとグリッパを持つ小型のロボットアーム。この課題では Gazebo の中のモデルを使う |
| crane_plus（rt-net） | CRANE+ V2 を ROS 2 で動かすためのパッケージ群。講座のイメージに入っている |
| joint1〜joint4・hand（j1〜j4） | 関節 1〜4 とグリッパの関節。joint3 が肘（おじぎ）。角度の単位は rad |
| Gazebo（Gazebo Sim 6.16・Fortress） | 物理シミュレータ。決められた刻みの物理計算を終えてから、中の時計を進める |
| ROS 2 Humble | ロボットのソフトウェアをつなぐための枠組み（Humble は版の名前） |
| ros2_control・joint_trajectory_controller | 関節の制御の仕組みと、関節の軌道を受け取ってその通りに動かす制御器 |
| JointTrajectory | 「どの時刻にどの角度」という点の列で表した関節の軌道のメッセージ |
| MoveIt・RViz | 動作計画の仕組みと、表示の道具。踊りには使っていないが、計測で使った起動ファイルは一緒に立てる |
| teleop | キーボードでロボットを動かすための ROS 2 のパッケージ（講座で紹介されたもの） |
| `/joint_states` | 関節の実際の角度が流れる ROS 2 のトピック |
| `/clock` | シム時刻が流れるトピック。`use_sim_time:=true` にしたノードは、この時計で動く |
| シム時刻 | Gazebo の中の時計。現実の時計（実時間）より遅く進むことがある |
| 実時間比（RTF・real time factor） | シム時刻の進み ÷ 実時間の進み。1 なら現実と同じ速さ |
| ros2 bag・rosbag2_py | ROS 2 のメッセージを記録する道具と、その記録を Python で読む部品 |
| JSONL（JSON Lines） | 1 行に 1 つの JSON を書いた文字のファイル |

## Docker と画面

| 用語 | 意味 |
|---|---|
| Docker・コンテナ | 環境ごと箱に入れて動かす仕組み |
| digest | イメージの中身から計算した指紋（sha256）。同じ digest なら中身は同じ |
| latest | イメージに付ける名札。後から中身が変わりうる |
| amd64・arm64 | CPU の種類。講座のイメージは Intel 向け（amd64）、Apple Silicon は arm64 |
| エミュレーション | 別の CPU の命令を翻訳して動かすこと |
| noVNC | コンテナのデスクトップをブラウザで見るための道具 |

## 曲と振付

| 用語 | 意味 |
|---|---|
| librosa | Python の音楽解析ライブラリ。`beat_track` で拍の時刻を出す |
| BPM | 1 分あたりの拍の数（テンポ） |
| hop 長 | 音を解析するときの刻みの幅（サンプル数） |
| onset | 音の立ち上がり |
| 小節頭 | 各小節の 1 拍目 |
| キーフレーム | 区切りとなる姿勢とその時刻。あいだは直線補間する |
| 拍位相 φ | 拍の中での位置（拍の頭で 0、次の拍の頭で 2π）。sin φ・cos φ の 2 つで表す |
| 進行度 | 経過時間 ÷ 曲の長さ（0〜1） |

## 学習

| 用語 | 意味 |
|---|---|
| 模倣学習（imitation learning） | お手本の動き（デモンストレーション）をまねるように学習させる方法 |
| 方策（policy） | 観測から行動を決める仕組み。ここでは学習したモデル |
| ACT（Action Chunking with Transformers） | 先の一定区間の行動をまとめて出す模倣学習の手法 |
| Transformer・エンコーダ・デコーダ | ACT が使うニューラルネットワークの形。入力を読む部分と、出力を作る部分 |
| チャンク（chunk） | まとめて出す行動の区間 |
| CVAE・VAE | 条件付き変分オートエンコーダ。同じ状況でのお手本の揺らぎを扱う部分 |
| KL ダイバージェンス | 2 つの分布の近さの指標 |
| LeRobot・LeRobotDataset | Hugging Face のロボット学習のライブラリと、そのデータ形式（v3） |
| PyTorch | 深層学習のライブラリ |
| MPS | Apple の GPU を PyTorch から使う仕組み |
| npz | NumPy の保存形式。ここでは関節の目標の列を受け渡すのに使う |
| action | 行動。その時刻の関節の目標角 5 つ |
| observation.state | 観測の状態。関節の角度 5 つ |
| observation.environment_state | 環境の状態。sin φ・cos φ・進行度の 3 つ |
| 一次遅れ・時定数 τ | 目標に、だんだん追いつく動き方と、その追いつく速さを決める値 |
| step・バッチサイズ・エポック | 学習の 1 回の更新・1 回に使うデータの数・データ全体を何周したか |
| 学習率 | 1 回の更新でどれだけ値を動かすか |
| 乱数の種（seed） | 乱数の出方を決める値 |
| 開ループ | 方策の出力を、次の入力に戻さない使い方 |
| 閉ループ | 自分の出力の結果を次の入力にする使い方 |
| temporal ensemble | 毎コマ推論し、同じ時刻に対する複数の出力を、時間方向に重みづけ平均する方法 |
| B5・v2・E1・B1〜B5・c1〜c5 | 学習の条件に付けた名前（設定は `act/batches/`） |

## 再生と解析

| 用語 | 意味 |
|---|---|
| 再生ノード player | npz（またはお手本）を読み、全体を 1 本の JointTrajectory にして制御器へ 1 回だけ送る、自作の ROS 2 のノード |
| t0 | 踊りの始まりのシム時刻 |
| 点・k・t_k | 50 Hz（0.02 秒ごと）に並べた時刻の点。k は点の番号、t_k ＝ t0 ＋ k ÷ 50。再生ノードのログやコードの中では「格子」と書いている |
| header.stamp | メッセージに付ける時刻。ここではシム時刻 |
| `/crane_dance/joint_target` | 再生ノードが、各点の目標を記録用に出すトピック |
| 学習の差・実行の差・全体の差 | 振付 c(t)・方策の出力 p(t)・実際の角度 q(t) の差。c − p・q − p・q − c |
| RMS | 二乗平均の平方根。ずれの平均的な大きさ |
| run1・run2 | 計測した 2 回（run1＝画面収録なし、run2＝画面収録あり） |
